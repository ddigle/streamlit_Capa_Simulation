실행 관리가 모은 실적(효율·UPEH·생산실적)으로 **표준 Capa 가 실제로 얼마나 실현됐는지 다시 계산**합니다.
손실을 설비 성능(효율·UPEH)과 가용 Capa 활용(Rundown·재공부족)으로 나눕니다.

`공정 상세` 탭의 조회일 · 공정 · 제품 · Stack · WF 속성은 사이드바 `Dynamic Capa 조건` 카드에서 고릅니다(그 탭을 열었을 때
섭니다). 사이드바 조회 조건 `샘플 데이터` 를 끄면 실적 DB 연결 전 화면을 봅니다 — 켜 둔 동안의 수치는 합성 샘플입니다.

#### 손실을 파고드는 화면

`요약` 탭 맨 아래 카드 다섯은 손실 한 칸씩 그 칸을 파고드는 화면으로 잇습니다 — 카드의 `열기` 를 누르면 그 화면이
열립니다. 카드 차례는 워터폴에서 손실이 차감되는 차례입니다.

| 카드 | 워터폴의 자리 | 여는 화면 |
|---|---|---|
| 효율 손실 | 표준 → 효율 반영(`표준 Capa − 효율 반영 Capa`) | 효율 실적 |
| UPEH 손실 | 효율 반영 → 실효(`효율 반영 Capa − 실효 Capa`) | UPEH 실적 |
| 수율 손실 | 양품 기준 차감 — 워터폴에 칸이 따로 없어 기타 Gap 에 듭니다 | 수율 실적 |
| 재공부족 미활용 | 실효 → 모델 실적(`실효 Capa − 모델 실적 Capa`) | 표준 대비 재공 현황 |
| 설비 가용 | 손실 이전의 전제 — 워터폴 밖입니다 | 가용설비 현황 |
