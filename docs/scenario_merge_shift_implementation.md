# 시나리오 월 머지·연도 Shift 구현 설명

[과제 정의서](task_scenario_merge_shift_2026-09-23.md)의 두 작업은 공통 기반 위에서
서로를 호출하지 않는 별도 서비스·UI·테스트와 기능별 커밋으로 분리한다.
시나리오 관리의 작업 선택에서 사용한다. 입력은 저장된 시나리오와 리비전이며,
현재 활성 시나리오를 처음 고르면 활성 리비전, 나머지는 최신 저장 리비전이 기본이다.
미저장 편집은 입력에 섞지 않는다.

## 월 머지

베이스의 월과 덧붙일 리비전에서 시작·종료 월 사이의 실제 월을 합친다. 양 끝을 포함하며
없는 중간 월이나 행은 만들지 않는다. 겹치는 월 목록을 표시하고 **저장 차단·베이스 사용·
덧붙일 쪽 사용**을 고르게 한다. 12개월을 하나씩 고르지 않도록 겹치는 월 전체에 한 번에
적용한다. 기본은 기존과 같은 **저장 차단**이다. 어느 쪽이 맞는지는 데이터로 판정할 수
없으므로 사용자가 선택하기 전에는 어느 쪽도 우선하지 않는다. 원본 리비전·월 범위가
바뀌면 기본값으로 돌아가 새 조건을 확인하게 한다.

선택한 쪽의 월 전체를 12개 월표에서 사용하며, 반대쪽의 해당 월 행은 모두 제외한다.
제품·공정 키가 달라도 행을 섞거나 빠진 값을 반대쪽으로 채우지 않는다. 월 없는 네 표와
가상제품 이력의 정책은 그대로다. 저장 전에 **월·겹침 여부·선택 출처·시나리오·리비전**을
항상 표시하며, 미리보기와 병합은 같은 월 선택 계획을 쓴다. 선택 기준과 월별 출처도 초기
리비전 메모에 기록한다. 결과의 12개 월표는 최소·최대뿐 아니라 **월 집합 전체가 같아야**
저장할 수 있다. 선택한 쪽 표에 월이 빠졌다면 반대쪽으로 보완하지 않고 오류를 표시한다.

월 없는 `RQ_CHIP_EQ`·`RQ_CHIP_QTY`·`RQ_MODULE`·`RQ_DISPLAY_ORDER`는 베이스를 그대로
복사한다. 네 표의 양쪽 행 수와 값 차이를 항상 보여 주고, 다르면 베이스만 쓴다는 경고를
표시한다. 행·컬럼 순서만 다른 것은 값 차이가 아니다. 표시순서는 공용 설정을 덮기 전의
저장 원본끼리 비교한다. 새 시나리오를 불러올 때 공용 표시순서를 적용하는 기존 정책은 같다.

## 연도 Shift

사용자가 이동할 연수를 정수로 직접 입력한다. **초기값은 0**이며 자동 검출·추천은 없다.
양수·음수를 모두 허용하고 0에서는 저장하지 않는다. 월표 12개의 연도만 옮기며 월 번호,
다른 컬럼, 월 없는 4표는 보존한다. `normalize_month_column`과 같은 **연도 1~9999,
월 1~12** 범위인지 검사하고 넘으면 저장을 막는다. 전후 범위는 나란히, 표별 월 범위·월 수·
행 수는 한 표에서 보여 준다. 머지의 월 축 일치 검사를 Shift에 새로 강제하지 않는다.

## 저장과 검증

두 기능은 `create_scenario`로 새 데이터셋·초기 리비전을 원자적으로 저장한다. 원본을
수정하거나 새 결과를 자동 활성화하지 않는다. 저장 후 목록 관리 또는 사이드바에서
명시적으로 불러온다. 조회기간·포함공정은 결과 전체, 확보·경고 기준은 원본(머지는 베이스)을
따른다. 이름은 사용자가 수정하며 원본 시나리오·리비전 ID와 적용 조건을 초기 리비전 메모에
항상 남긴다. 원천 Core Data를 재합성하지 않는다. 스키마·마이그레이션·계산식 변경은 없다.
RQ 16표와 가상제품 복제 이력을 함께 보존한다. Shift는 원본 이력을 그대로 옮긴다.
머지는 월 없는 이력 전체를 양쪽 리비전에서 합치며 같은 `제품정보 + Stack`의 복제 원본
제품·Stack이 같으면 한 건만 남기고, 다르면 충돌 내용을 보여 주고 저장을 막는다. 월 범위는
12개 RQ에만 적용한다. 이력을 미리 볼 수 있고, 초기 리비전·16표와 같은 트랜잭션으로
저장하여 중간 실패 시 모두 롤백한다. 기존 이력 표를 쓰므로 스키마 변경은 없다.

기본 2025~2030 밖에 저장된 월도 실제 활성 데이터 범위까지 월 선택기를 넓혀 조회할 수 있다.
조건 변경마다 미리보기를 다시 만들고 동일 제출의 중복 저장을 막는다. 자동화 검증은
원본 16표 불변, 저장본 재조회, 중간 월 누락·겹침의 세 선택, 무월 값 차이, 저장된 표시순서와 공용
조회 분리, 활성 편집본 보존을 확인한다. 8503의 실제 브라우저에서는 합성 원본으로
미리보기→저장→불러오기→HOME 왕복을 확인하며 검증 후 로컬 DB를 백업본으로 복원한다.
Shift의 양수·음수·1/9999년 경계와 2031년 조회, 두 작업의 조건 변경 후 두 번째 저장도
검증한다. 공통 기반 커밋을 유지하면 각 기능의 서비스·UI·테스트를 독립적으로 되돌릴 수 있다.
