# AGENTS 13장 — 문서 우선순위

## 13. 문서 우선순위

- 실제 동작: 현재 코드와 테스트
- 확정된 업무 결정: `docs/records/decisions.md`(기록 — 정한 것은 다시 묻지 않는다) · 향후 항목: `docs/TODO.md`
- 사용자 설치·운영 안내: `README.md`
- 개발 구조와 에이전트 작업 규칙: `AGENTS.md`(색인) — 장마다 `docs/rules/`, 파일별 책임 `docs/reference/files/`
- 화면 설계 · 검수 규칙(규칙 id · 수준 · 판단 질문 · 결정 기록): `docs/design_rules.md` — 구현 규칙은 `docs/rules/08` · `09`
- 모듈 담당자 규칙·코어 공개 창구: `docs/module_guide.md`(담당자 사람용 안내서 `docs/module_colleague_guide.md` 는 그것을
  옮긴 것 — 어긋나면 지침서)
- 직전 세션 인수인계 스냅샷: `HANDOFF.md`. 정본이 아니라 그 시점 상태의 기록이므로 위 네
  항목과 어긋나면 위를 따른다.

문서와 코드가 다르면 코드만 따라가고 끝내지 말고, 차이의 원인을 확인한 후 관련 문서를
함께 수정한다.
